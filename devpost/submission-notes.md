# Devpost 填写说明

- 将 `about-the-project.md` 的全文粘贴到 **About the project**。七个标题与 Devpost 模板一致；正文使用第一人称单数，适合个人项目，避免暗示尚未确认的团队经历。
- `built-with.txt` 提供 15 个真实使用的技术和工具标签，低于截图要求的 25 个上限。Devpost 若没有完全一致的候选，选最接近的正式名称即可；优先添加 TypeScript、Next.js、React、Node.js、Alibaba Cloud、Qwen、Web Audio API。
- **Voiskey 是参赛赛道背景，并没有调用 Voiskey API**，所以没有把它列为 API 技术标签。当前朗读用浏览器系统语音，没有使用云 TTS。
- 文案中的范例来自本项目样例或已记录的真实 API 验证；没有添加用户量、体验改善比例、获奖、真人麦克风表现或公开部署等未经验证的成果。
- 公开项目主页已上线：https://yujun-lu.github.io/absurdly-yours/ 。它提供明确标记的交互预置样例；完整语音与 AI 应用的源码在 https://github.com/Yujun-Lu/absurdly-yours 。未来计划中的 hosted version 指带访问控制和用量限制的完整在线 AI 服务。
- 录音管线已用合成语音测试；提交现场前建议用实际麦克风试说一句。不要把本机 `localhost` 或 `127.0.0.1` 链接填成供评委访问的公开链接。
