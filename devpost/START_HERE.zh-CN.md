# Devpost 填写与上传

## About the project

复制 `about-the-project.md` 的完整英文正文，保留七个 Markdown 标题。使用第一人称 I，适合个人作品；若实际有其他队友，可以自行改成 we。

## Built with

按 `built-with.txt` 逐项填写。这 15 个标签都来自实际使用的技术和开发工具，低于截图中的 25 个上限。不要把未使用的 Voiskey API、云 TTS、WebSocket 或数据库加入技术栈。

## Try it out

优先添加项目主页：

https://yujun-lu.github.io/absurdly-yours/

也可以再添加完整源码：

https://github.com/Yujun-Lu/absurdly-yours

主页提供无需 Key 的双语交互预置样例，并明确标注来源。它不调用 AI、不接收麦克风；真实语音转写和自定义创作在完整 Next.js 应用中运行，启动方式见仓库 README。

## Image gallery

建议从上传包的 `gallery/` 按顺序上传四个文件（仓库中的同一套图片位于 `docs/assets/`）：

1. `hero.png`：封面。
2. `gallery-01-voice.gif`：语音 → 转写 → 创作。
3. `gallery-02-flair.gif`：三档骚气。
4. `gallery-03-bulletin.gif`：公报、加冕与中文表达。

全部为 1200×800、3:2；最大文件约 0.80 MB。没有用满 15 张上限，避免重复。GIF 本身没有声音。如果平台上传或预览 GIF 有问题，换用同名 PNG，通常无需两种都上传。

画廊右上角准确标注了来源：语音流程使用合成语音输入，调用真实转写和生成接口；换挡与公报使用明确选择的预置样例。
